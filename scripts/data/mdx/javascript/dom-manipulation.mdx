<Summary>
  The Document Object Model (DOM) is a programming interface for web documents.
  It represents the page so that programs can change the document structure,
  style, and content. The DOM represents the document as nodes and objects; that
  way, programming languages can connect to the page.
</Summary>

<InfoBlock>
  <InfoBlockHeader title="Selecting Elements" tag="QUERY_SELECTOR" />
  <InfoBlockText>
    Before you can manipulate elements, you must first access them within the
    document tree. Modern JavaScript provides powerful methods to target nodes
    by ID, class, or tag name.
  </InfoBlockText>

  <InfoBlockListContainer>
    <InfoBlockListItem>
      <InfoBlockInlineCode>document.getElementById()</InfoBlockInlineCode> -
      Fast, specific selection by unique ID.
    </InfoBlockListItem>

    <InfoBlockListItem>
      <InfoBlockInlineCode>document.querySelector()</InfoBlockInlineCode> -
      Versatile, uses CSS selector syntax.
    </InfoBlockListItem>

    <InfoBlockListItem>
      <InfoBlockInlineCode>document.querySelectorAll()</InfoBlockInlineCode> -
      Returns a NodeList of all matches.
    </InfoBlockListItem>

  </InfoBlockListContainer>
  ```js
  const hero = document.querySelector('.hero-title');
```
</InfoBlock>

<InfoBlock>
  <InfoBlockHeader title="Modifying Content" tag="Inner_html" />
  <InfoBlockText>
    Once selected, element properties become mutable. You can change text,
    inject HTML, or modify attributes dynamically based on user interaction or API data.
  </InfoBlockText>

  <InfoBlockListContainer>
    <InfoBlockListItem>
      <InfoBlockInlineCode>element.textContent</InfoBlockInlineCode> -
      Safe way to set text, ignores HTML tags.
    </InfoBlockListItem>

    <InfoBlockListItem>
      <InfoBlockInlineCode>element.innerHTML</InfoBlockInlineCode> -
      Parses string as HTML. Watch for XSS!
    </InfoBlockListItem>

    <InfoBlockListItem>
      <InfoBlockInlineCode>element.setAttribute()</InfoBlockInlineCode> -
      Update IDs, src, href and more.
    </InfoBlockListItem>

  </InfoBlockListContainer>

</InfoBlock>
